# 设计依据与取舍

本次迁移沿用第 8 套行内工作台及后续已确认修订, 当前规则以共享配置为准, 下列为此前调研记录的应用摘要

| 参考 | 应用到本系统 | 未直接照搬的部分 |
| --- | --- | --- |
| [Carbon 行内操作](https://carbondesignsystem.com/components/data-table/usage/#inline-actions) | 编辑和评论独立, 常驻行末 | 表格样式和选择整行的高亮 |
| [Atlassian Inline edit](https://atlassian.design/components/inline-edit) | 原位置切换阅读和编辑 | 产品自身的边框色与编辑高度 |
| [GOV.UK Summary list](https://design-system.service.gov.uk/components/summary-list/#adding-actions-to-each-row) | 动作名称包含作用对象 | 键值式列表结构 |
| [NN/g 渐进披露](https://www.nngroup.com/articles/progressive-disclosure/) | 过程, Markdown 与备注详情按需展示 | 隐藏常用编辑与评论入口 |
| [Fluent 层级](https://fluent2.microsoft.design/elevation) | 用阴影区分独立面板 | 正文套卡片和重复阴影 |

已对照用户提供的 awesome-design-md-main, codex 截图, open-design-main/design-systems, ui-main 四组本地资料, 其中 IBM 分析和 shadcn 数据表用于检查文字层级与行操作, 不把分析材料当作官方强制规则

用户截图直接约束当前菜单对勾, 复选底板, 备注标签与浮窗, 20px 彩色 agent, 14px 编辑与评论图标及浅色输入边线, 这些后续确认覆盖早期选中灰底, 绿色状态和深色输入焦点

2026-09-17 的修订根据用户对实际组件页的反馈调整, 没有新增外部研究结论, 本轮以 [控件几何](foundations.html#control-geometry) 和共享配置记录以下取舍:

- 点击区与视觉背景分别定义, 普通图标底板保持 28px 和 8px 圆角, 只有粗指针把点击区扩大到 44px, 视口变窄不再同时放大按钮背景与行间距
- Composer 底部使用 44px 工具栏, 图标 hover 背景为 32px 圆形, 审批与模型入口默认透明, hover 时呈现高 32px 的胶囊背景, 与周围圆形控件保持同一形状关系, 30px 发送圆, 右侧按钮间隔 2px, 右侧留白 5px, 发送圆到输入框外边缘保留 8px, 其中内容间距为 7px, 边框为 1px
- 当前编辑或确认流程中的保存, 取消和弹窗删除保留常显浅底, 设置, 切换, 查看及可选操作默认透明, 所有按钮 hover 与按下统一使用与删除图标相同的 `--action-hover-bg` 中性灰底, 该变量读取 `--surface-hover`, 不按 tone 改变 hover 底色, 文字与图标保留语义颜色, 会话切换入口按可选操作处理, 菜单展开不作为入口背景常亮的理由
- 已确认, 待处理计数和备注数量标签附近没有圆形按钮, 使用两侧平直的 10px 圆角矩形, 作为状态摘要保留常显浅灰背景, 背景高度固定为 30px, 触屏点击区可以增加, 文字与背景不随视口变窄而增高
- 资料标签采用文件目录截图中的白底胶囊与 8px 间距, 内部左右 12px, 上下 6px, 14px 图标与文字相隔 6px, 类别图标使用共享撞色色板, 完成状态仍使用中性色
- 网页, 命令与通用工具图标分别使用蓝色, 琥珀色和紫色, 图标颜色表达类别, 不改变输出文字的状态含义
- 消息代码块, 工具输出和 Markdown 原文共用安全文本高亮, 浅色琥珀 `#99670a`, 深色琥珀 `#eac16b`, 标记与正文分色, 保留原文及换行用于复制
- Agent 保留蓝色轮廓, 替换紫色形状, 增加琥珀, 珊瑚和青色, 默认使用五款, 薄荷环形仅归档, 首次随机分配后按身份保持一致, 避免每次渲染改变身份图形
- 上下文条目依据组件容器而非页面宽度换行, 仅容器不超过 360px 时把操作移至下一行, 两行之间保持 2px

`verification/geometry.mjs` 将控件几何与响应式边界纳入回归, 分别检查精细指针和粗指针, 不把窗口宽度作为触屏判断条件

本轮同时把行内工作台拆为共享组件, 用组件边界约束后续调整:

- `Panel` 统一外壳与插槽, `SessionSwitcher` 管理菜单, `ReviewPanel` 管理清单编辑和撤销, `AnnotationPopover` 管理备注详情与定位, 引用与备注内容区在查看, 编辑与 hover 时始终与面板同色, 浅色为白底, 深色读取对应面板底色, 只有具体按钮在 hover 时使用 `--action-hover-bg` 灰底, 内部无分割线, 四项均有独立规范页
- 工作台使用系统的消息, 过程摘要, 工具, 子代理, 输入框与上下文编辑, 页面只保存会话数据, 连接事件和组织布局, 示例中的组件样式与行为不保留副本
- 输入框采用受控值和插槽接收备注, 发送前由页面检查未保存内容, 同步返回 `false` 时保留草稿, 共享 `Composer` 不依赖某个评审对象
- 多会话通过 `active` 关闭非活动菜单与浮窗, 上下文通过 `triggerRef` 返回所属触发按钮, 避免跨会话焦点跳转
- 完全访问的标题, 图标和对勾使用 `--permission-danger`, 描述保持中性, 上下文标识与分组标签使用 `--context-accent` 琥珀色表达控件与分组结构, 内容与复选不染色
- 命令图标采用 24 x 24 画布内的 20 x 14 窗口轮廓, 保持描边比例, DOM 与 React 使用同一节点数据, 不压缩原来的正方形图标

这些实现边界使规范页与集成示例引用同一个控件, 调整共享组件会同步影响两处, 不依赖逐页复制样式

与原系统冲突的处理:

- 保留原有上下文排序, 移除, 添加和并入能力, 增加确认快照以区分编辑状态与发送范围
- 原固定机器人图集改为透明彩色 agent, 功能图标使用固定 Lucide 细线子集, 命令窗口为共享数据中的本地图形
- 模型菜单与审批, 添加和会话菜单统一使用 `--menu-item-radius: var(--radius-control)` 的 8px 圆角矩形, 含说明的多行选项也保持此值, 不继承浮窗大圆角或工具栏入口胶囊形状, 菜单项默认透明, 选中仅显示对勾, hover 使用统一灰底, 键盘焦点轮廓保留
- 原草稿整块灰背景改为主题画布与分组线, 独立评审面板可以并排, 窄屏改为上下排列
- 以浅色小样确定基础关系, 深色通过同一组语义变量适配, 不复制一套组件样式

这些取舍为本项目的应用判断, 不代表参考系统规定了本项目的具体数值

本轮根据宽屏截图收敛内容宽度: Composer 沿用 680px 阅读栏上限并居中, ReviewPanel 上限为 560px, 添加菜单上限为 320px, 避免正文与行末操作之间产生随屏幕增长的空白, 上下文分组标题从 12px 调为 14px / 500, 辅助说明保留 12px

按钮的字色表达语义, 背景表达当前流程是否需要用户作出决策: 可选中性操作用灰字, 红色表示移除或需警示的操作, 紫色用于需要注意的选择, 绿色对应并入, 并入与全部并入使用同一颜色, 蓝色对应确认, hover 保留字色, 完成状态仍为中性色

用户提供的 Cancel 与 Close side chat 截图定义当前决策按钮的浅底样式, 后续 Composer 与会话入口截图补充默认透明的可选操作, 两者统一为 Button 的 soft 和 ghost 变体, 圆角独立选择 rounded 或 pill, 常规面板使用 10px 圆角矩形, 圆形控件集中的工具栏使用 9999px 胶囊圆角, 视觉高 32px, 不使用描边, 保留键盘焦点轮廓, 触屏只将点击区扩大到 44px

菜单选项继续以对勾表示选中, 正文链接保留内容布局, 分组副标题和确认栏说明移除以减少重复信息, 后续新增动作按操作职责选择背景, 不因位置或已有浅底样式直接复制按钮层级
