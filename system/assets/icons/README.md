# 图标库

30 个图形由 Codex 内置生图工具一次生成, 使用透明背景, 统一圆角轮廓, 同一张图集供所有组件使用

- `atlas.png`: 原始透明图集, 1374 × 1145 像素
- `atlas.json`: 图集尺寸与切图坐标, 每项为横坐标, 纵坐标, 正方形边长
- `prompt.txt`: 实际使用的生成提示词

切图按每个图形的非透明轮廓计算, 四周保留留白, 用遮罩裁切显示, 不修改原始图集, 也不拉伸单个图形

子代理, 工具调用与消息操作使用 16 像素, 标签图标使用 13 像素, 图标颜色继承当前文字颜色, 支持深浅主题, 悬停, 选中和禁用状态

图集顺序为 6 列 5 行, 其中上移与发送共用向上箭头, 因此规范页有 31 个用途预览, 分支和分享是独立图形, 保持各自语义

扩充时保留现有条目的名称与坐标, 为新增图形添加索引, 避免已使用的组件出现错位
